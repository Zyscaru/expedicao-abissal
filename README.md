# Expedição Abissal

Jogo de Python **intermediário**. O submarino-robô ARGO desce ao fundo do mar atrás do naufrágio do *Aurora*, e o software dele é você quem escreve. São 18 missões em 6 zonas, cada vez mais fundas:

- **Funções e listas:** expandir e compactar ordens, simular rotas com correntes marinhas.
- **Dicionários e conjuntos:** inventários, ecos confirmados do sonar, mapa de perigo.
- **Classes:** `@property`, `__str__`, `__lt__`, exceções próprias, herança e polimorfismo.
- **Pilotos com estado e exceções:** oxigênio, enguias em patrulha, `try/except/else`.
- **Recursão e geradores:** flood fill, `yield` em espiral, backtracking.
- **Algoritmos:** busca em largura com `deque`, programação dinâmica e busca com chaves e portas.

O Python roda direto no navegador (Skulpt) e o jogo funciona offline depois de aberto uma vez.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.
